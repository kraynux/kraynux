### [OMEGA-SERV](https://github.com/kraynux/omega-serv)  
<div align="center">
  <img src="docs/assets/omega-serv.png" alt="Omega-Serv" width="384">
</div><br>

**OMEGA-SERV** is a complete, powerful, and hardened-by-default “**LINUX SERVER SUITE**” TUI application.

Multi-instance, integrated WAF and Active Defense, preconfigured profiles, reverse proxy, TLS, PHP, aliases, rewrites, redirects,

## All OMEGA-... projects: 
### Security & scanning

- **[omega-suite](https://github.com/kraynux/omega-suite)** – all scanning tools in a single interface.  
- **[omega-scan](https://github.com/kraynux/omega-scan)** – Server configuration scanner.  
- **[omega-check](https://github.com/kraynux/omega-check)** – Port and service scanner.  
- **[omega-deep](https://github.com/kraynux/omega-deep)** – Network architecture scanner.  
- **[omega-fold](https://github.com/kraynux/omega-fold)** – Local and remote directory scanner.  
- **[omega-stress](https://github.com/kraynux/omega-stress)** – Server load testing tool.  
- **[omega-track](https://github.com/kraynux/omega-track)** – Digital tracer for web paths and identity.  
- **[omega-fuzz](https://github.com/kraynux/omega-fuzz)** – Server vulnerability scanner.  

### Servers & backends

- **[omega-serv](https://github.com/kraynux/omega-serv)** – Hardened web server with an integrated firewall and defense system.  
- **[omega-fire](https://github.com/kraynux/omega-fire/)** – Firewall management, monitoring, and logs on Linux.  
- **[omega-log](https://github.com/kraynux/omega-log)** – Server log manager.  
- **[omega-waf](https://github.com/kraynux/omega-waf)** – WAF engine (Magnet) for servers compatible with OMEGA-SERV and Lighttpd.  
- **[omega-jail](https://github.com/kraynux/omega-jail)** – Fail2ban jail pack compatible with and adapted for OMEGA-: SERV, FIRE, and WAF.  

### Libraries & utilities

- **[omega-lib](https://github.com/kraynux/omega-lib)** – Python library for the omega- tools.
