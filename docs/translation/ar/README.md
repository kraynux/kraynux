## كل مشاريع OMEGA-...:



### الأمان والفحص

- **[omega-suite](https://github.com/kraynux/omega-suite)**  – كل أدوات الفحص في واجهة واحدة.
- **[omega-scan](https://github.com/kraynux/omega-scan)** – ماسح لتهيئات الخادم.
- **[omega-check](https://github.com/kraynux/omega-check)** – ماسح للمنافذ والخدمات.
- **[omega-deep](https://github.com/kraynux/omega-deep)** – ماسح لبنية الشبكة.
- **[omega-fold](https://github.com/kraynux/omega-fold)** – ماسح للمجلدات المحلية والبعيدة.
- **[omega-stress](https://github.com/kraynux/omega-stress)** – أداة اختبار الحمل للخوادم.
- **[omega-track](https://github.com/kraynux/omega-track)** – متتبّع رقمي للمسار والهوية على الويب.
- **[omega-fuzz](https://github.com/kraynux/omega-fuzz)**  – ماسح لثغرات الخادم.


### الخوادم والخوادم الخلفية

- **[omega-serv](https://github.com/kraynux/omega-serv)** – خادم ويب مُحصَّن مع جدار ناري ونظام دفاع مدمجين.
- **[omega-fire](https://github.com/kraynux/omega-fire/)** – إدارة الجدار الناري والمراقبة والسجلات على Linux.
- **[omega-log](https://github.com/kraynux/omega-log)** – مدير سجلات الخادم.
- **[omega-waf](https://github.com/kraynux/omega-waf)** – محرك WAF (magnet) للخوادم متوافق مع OMEGA-SERV وLIGHTTPD
- **[omega-jail](https://github.com/kraynux/omega-jail)** – حزمة jails لـ Fail2ban متوافقة ومكيّفة لـ OMEGA-: SERV وFIRE وWAF.

### المكتبات والأدوات المساعدة

- **[omega-lib](https://github.com/kraynux/omega-lib)** – مكتبة Python لأدوات omega-.

## Stack / المهارات

- **اللغات:** Python, Bash, Lua, SQL, Html
- **الأنظمة:** Linux (Arch، شبكات TCP/IP)
- **الويب والخوادم:** Lighttpd, vsFTPd, Tailscale, Fail2ban, Nftables
- **المواضيع:** محرك HTTP، وTLS، والتصفية على مستوى التطبيق، والنواة
- **الأدوات:** Git، وDocker، وMarkdown، وأدوات CLI للتحليل (grep وawk وjq وغيرها)
