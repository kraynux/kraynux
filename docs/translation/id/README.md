## Semua proyek OMEGA-...:



### Keamanan & pemindaian

- **[omega-suite](https://github.com/kraynux/omega-suite)**  – semua alat pemindaian dalam satu antarmuka.
- **[omega-scan](https://github.com/kraynux/omega-scan)** – Pemindai konfigurasi server.
- **[omega-check](https://github.com/kraynux/omega-check)** – Pemindai port dan layanan.
- **[omega-deep](https://github.com/kraynux/omega-deep)** – Pemindai arsitektur jaringan.
- **[omega-fold](https://github.com/kraynux/omega-fold)** – Pemindai folder lokal dan jarak jauh.
- **[omega-stress](https://github.com/kraynux/omega-stress)** – Penguji beban untuk server.
- **[omega-track](https://github.com/kraynux/omega-track)** – Pelacak digital jalur dan identitas web.
- **[omega-fuzz](https://github.com/kraynux/omega-fuzz)**  – Pemindai kerentanan server.


### Server & backend

- **[omega-serv](https://github.com/kraynux/omega-serv)** – Server web yang diperkuat dengan firewall dan sistem pertahanan terintegrasi.
- **[omega-fire](https://github.com/kraynux/omega-fire/)** – Pengelolaan firewall, monitoring, dan log di Linux.
- **[omega-log](https://github.com/kraynux/omega-log)** – Pengelola log server.
- **[omega-waf](https://github.com/kraynux/omega-waf)** – Mesin WAF (magnet) untuk server yang kompatibel dengan OMEGA-SERV dan LIGHTTPD
- **[omega-jail](https://github.com/kraynux/omega-jail)** – Paket jail Fail2ban yang kompatibel dan disesuaikan untuk OMEGA-: SERV, FIRE, dan WAF.

### Pustaka & utilitas

- **[omega-connect](https://github.com/kraynux/omega-connect)** – utilitas interkoneksi lokal dan jarak jauh untuk alat omega-.
- **[omega-lib](https://github.com/kraynux/omega-lib)** – pustaka Python untuk alat omega-.
