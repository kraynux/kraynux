## OMEGA-... の全プロジェクト：



### セキュリティとスキャン

- **[omega-suite](https://github.com/kraynux/omega-suite)**  – すべてのスキャンツールを 1 つのインターフェースに。
- **[omega-scan](https://github.com/kraynux/omega-scan)** – サーバー設定のスキャナー。
- **[omega-check](https://github.com/kraynux/omega-check)** – ポートとサービスのスキャナー。
- **[omega-deep](https://github.com/kraynux/omega-deep)** – ネットワーク構成のスキャナー。
- **[omega-fold](https://github.com/kraynux/omega-fold)** – ローカルおよびリモートのフォルダーのスキャナー。
- **[omega-stress](https://github.com/kraynux/omega-stress)** – サーバー向け負荷テストツール。
- **[omega-track](https://github.com/kraynux/omega-track)** – 経路と Web 上のアイデンティティを追うデジタルトレーサー。
- **[omega-fuzz](https://github.com/kraynux/omega-fuzz)**  – サーバーの脆弱性スキャナー。


### サーバーとバックエンド

- **[omega-serv](https://github.com/kraynux/omega-serv)** – ファイアウォールと防御システムを統合した堅牢な Web サーバー。
- **[omega-fire](https://github.com/kraynux/omega-fire/)** – Linux でのファイアウォール管理、監視、ログ。
- **[omega-log](https://github.com/kraynux/omega-log)** – サーバーのログ管理ツール。
- **[omega-waf](https://github.com/kraynux/omega-waf)** – OMEGA-SERV と LIGHTTPD に対応したサーバー向け WAF エンジン（magnet）
- **[omega-jail](https://github.com/kraynux/omega-jail)** – OMEGA-: SERV、FIRE、WAF に対応・適合した Fail2ban の jail パック。

### ライブラリとユーティリティ

- **[omega-lib](https://github.com/kraynux/omega-lib)** – omega- ツール用の Python ライブラリ。

## Stack / スキル

- **言語:** Python, Bash, Lua, SQL, Html
- **システム:** Linux（Arch、TCP/IP ネットワーク）
- **Web とサーバー:** Lighttpd, vsFTPd, Tailscale, Fail2ban, Nftables
- **テーマ:** HTTP エンジン、TLS、アプリケーションフィルタリング、カーネル
- **ツール:** Git、Docker、Markdown、CLI 分析ツール（grep、awk、jq など）
