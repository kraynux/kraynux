### [OMEGA-SERV](https://github.com/kraynux/omega-serv)
<div align="center">
  <img src="../../assets/omega-serv.png" alt="Omega-Serv" width="512">
</div><br>

**OMEGA-SERV** เป็นแอปพลิเคชัน TUI "**LINUX SERVER SUITE**" ที่ครบถ้วน ทรงพลัง และเสริมความแข็งแกร่งตั้งแต่ค่าเริ่มต้น

หลายอินสแตนซ์, WAF และการป้องกันเชิงรุกในตัว, โปรไฟล์ที่ตั้งค่าไว้ล่วงหน้า, reverse proxy, TLS, PHP, alias, การเขียนใหม่, การเปลี่ยนเส้นทาง,
การยืนยันตัวตน, ตัวจัดการล็อก (การดูและระบบอัตโนมัติ), การสำรองและกู้คืน,... ผลิตภัณฑ์เดียวสำหรับโครงสร้างพื้นฐานการโฮสต์ที่ครบถ้วน ปลอดภัย และดูแลง่าย

## โปรเจกต์ OMEGA-... ทั้งหมด:



### ความปลอดภัยและการสแกน

- **[omega-suite](https://github.com/kraynux/omega-suite)**  – เครื่องมือสแกนทั้งหมดในอินเทอร์เฟซเดียว
- **[omega-scan](https://github.com/kraynux/omega-scan)** – เครื่องสแกนการกำหนดค่าเซิร์ฟเวอร์
- **[omega-check](https://github.com/kraynux/omega-check)** – เครื่องสแกนพอร์ตและบริการ
- **[omega-deep](https://github.com/kraynux/omega-deep)** – เครื่องสแกนสถาปัตยกรรมเครือข่าย
- **[omega-fold](https://github.com/kraynux/omega-fold)** – เครื่องสแกนโฟลเดอร์ภายในเครื่องและระยะไกล
- **[omega-stress](https://github.com/kraynux/omega-stress)** – เครื่องทดสอบโหลดสำหรับเซิร์ฟเวอร์
- **[omega-track](https://github.com/kraynux/omega-track)** – เครื่องติดตามดิจิทัลด้านเส้นทางและตัวตนบนเว็บ
- **[omega-fuzz](https://github.com/kraynux/omega-fuzz)**  – เครื่องสแกนช่องโหว่ของเซิร์ฟเวอร์


### เซิร์ฟเวอร์และแบ็กเอนด์

- **[omega-serv](https://github.com/kraynux/omega-serv)** – เว็บเซิร์ฟเวอร์ที่เสริมความแข็งแกร่ง พร้อมไฟร์วอลล์และระบบป้องกันในตัว
- **[omega-fire](https://github.com/kraynux/omega-fire/)** – การจัดการไฟร์วอลล์ การมอนิเตอร์ และล็อกบน Linux
- **[omega-log](https://github.com/kraynux/omega-log)** – ตัวจัดการล็อกของเซิร์ฟเวอร์
- **[omega-waf](https://github.com/kraynux/omega-waf)** – เอนจิน WAF (magnet) สำหรับเซิร์ฟเวอร์ที่เข้ากันได้กับ OMEGA-SERV และ LIGHTTPD
- **[omega-jail](https://github.com/kraynux/omega-jail)** – ชุด jail ของ Fail2ban ที่เข้ากันได้และปรับให้เหมาะกับ OMEGA-: SERV, FIRE และ WAF

### ไลบรารีและเครื่องมือ

- **[omega-connect](https://github.com/kraynux/omega-connect)** – ยูทิลิตีเชื่อมต่อภายในเครื่องและระยะไกลสำหรับเครื่องมือ omega-
- **[omega-lib](https://github.com/kraynux/omega-lib)** – ไลบรารี Python สำหรับเครื่องมือ omega-
